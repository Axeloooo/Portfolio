## Problem

This follows two lectures from Andrej Karpathy's Neural Networks: Zero to Hero series, "Let's build GPT" and "Let's reproduce GPT-2 (124M)". The README describes the path from a character-level transformer up to the GPT-2 124M architecture and training recipe. The repo restructures the lecture code into an installable `src/` package with a CLI and tests. Only the architecture is at 124M scale; the training runs here use a small configuration.

## Architecture diagram

```text
Groups
  data.py: input.txt (packaged), CharTokenizer, split_tokens 90/10, DataLoaderLite, get_batch
  model.py: GPTConfig, GPT, Block x n_layer, CausalSelfAttention, MLP, configure_optimizers (AdamW)
  train.py: train: accum, clip, get_lr, estimate_loss

Flow
  __main__.py / train.main --> data.py
  CharTokenizer --(vocab size)--> GPTConfig
  input.txt (packaged) --> CharTokenizer
  CharTokenizer --> split_tokens 90/10
  split_tokens 90/10 --> DataLoaderLite
  split_tokens 90/10 --> get_batch
  GPTConfig --> GPT
  GPT --> Block x n_layer
  Block x n_layer --> CausalSelfAttention
  Block x n_layer --> MLP
  GPT --> configure_optimizers (AdamW)
  DataLoaderLite --> train: accum, clip, get_lr
  GPT --> train: accum, clip, get_lr
  configure_optimizers (AdamW) --> train: accum, clip, get_lr
  get_batch --> estimate_loss
  __main__.py / train.main --(after training)--> estimate_loss
  GPT --> generate: temperature, top-k
```

`python -m gpt_from_scratch` calls `train.main`, which reads the packaged Tiny Shakespeare text, tokenizes it by character, splits it 90/10, trains a `GPT` from `model.py`, then prints train and validation loss and a sample from `generate`.

## Key decisions

- **Two attention paths.** `CausalSelfAttention` keeps a written-out masked softmax next to `scaled_dot_product_attention`, chosen by a `flash` flag. `tests/test_model.py::test_manual_attention_matches_flash` checks they agree to 1e-5.
- **GPT-2 124M defaults, small CLI defaults.** `GPTConfig` defaults to 1024 context, 12 layers, 12 heads, 768 dims and a vocab padded to 50304. The CLI defaults to 4 layers and 128 dims so it can run on a CPU, and sets the vocab size from the character tokenizer rather than 50304. A test builds the config with the unpadded GPT-2 vocab (50257) on the `meta` device and asserts 124,439,808 parameters, so it needs no memory (`tests/test_model.py`).
- **Tested gradient accumulation.** Following lecture 9 (weight tying, scaled residual init, AdamW decay on matrices only, warmup plus cosine learning rate, gradient clipping), `train` divides each micro-batch loss by `grad_accum_steps`, and `tests/test_train.py` checks that accumulated gradients match one larger batch. The CLI learning rate defaults to 3e-3 while `train()` defaults to the lecture's 6e-4.
- **Packaged like a library.** `src/` layout, mypy strict, ruff, black, and CI on Python 3.10 and 3.13 (`pyproject.toml`, `.github/workflows/ci.yml`). Releases are automated with commitlint and semantic-release (`.releaserc.json`, `release.yaml`).

## Challenges

- **Dataset missing from installs.** `input.txt` first lived in `data/`, outside the package, so a regular install lacked it. Commit `7fe2ba4` moved it into `src/gpt_from_scratch/` as package data, added a `--data` flag and train/val loss reporting, and added a test.
- **Release workflow.** It was reworked twice: a custom release token (`0fb8313`), then the built-in `GITHUB_TOKEN` (`e611d03`), with back-merge commits from `main` to `devel`.
- **Typing a PyTorch model.** `model.py` keeps a few `# type: ignore` comments, and `pyproject.toml` sets `disallow_untyped_calls = false` because torch's backward calls are untyped.

## Results

- `python -m gpt_from_scratch` is wired to train a character-level GPT, printing per-step loss, learning rate and gradient norm, then train and validation loss and a 200-token sample. `test_cli_runs` exercises this path.
- The repo has 19 test functions across `tests/test_model.py` and `tests/test_train.py`, covering causality, attention equivalence, parameter count, optimizer groups and gradient accumulation.
- The README's "Not included" section lists what was not done: the GPT-2 124M pretraining run on FineWeb-Edu, HellaSwag evaluation, loading Hugging Face weights, `torch.compile` and multi-GPU training.
- The repo records no loss values or sample output.
