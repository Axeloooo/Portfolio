## Problem

The repository is a set of lessons that connect the arithmetic inside a neural network to the Keras calls that automate it: trace values through a small network, study how gradients drive learning, then move to tabular data, handwritten digits, convolution, attention and pretrained models (`README.md`). The notebooks follow the labs of the Deep Learning with Keras course; this repo adds the Colab-first packaging, fixes, refinements to some lessons (activation functions, regression) and the README and contributor documentation below.

## Key decisions

- **Colab only, no local setup.** All `!pip install` cells stay commented out and there is no lockfile; the README says to leave them commented (commit `0641241`).
- **Standalone notebooks.** Each has its own setup cells so it can run independently (`CONTRIBUTING.md`, `README.md`).
- **NumPy before Keras.** The early notebooks build forward and backward passes by hand so the later `model.fit` calls are not opaque (`README.md` conclusion).
- **Reproducible reruns.** `backward-propagation.ipynb` fixes `np.random.seed(42)` (commit `c87e156`); the CNN notebook always encodes the original digit labels so the cell is safe to rerun (commit `2ccc52f`).
- **Correct the docs, not just the code.** `README.md` states that `transformers-with-Keras.ipynb` builds an LSTM encoder-decoder with one custom `SelfAttention` layer, not a full Transformer, although the notebook's own intro still says transformer.

## Challenges

- **Course environment to Colab.** Commit `0641241` ("make all eight notebooks runnable end to end in Google Colab") ported the notebooks, and the README admits some lesson text still refers to the original course environment.
- **No automated checks.** There are no tests, and `.github/workflows/release.yaml` only runs semantic-release on `main`; it does not execute notebooks. Validation is a manual run in a fresh Colab runtime.
- **Slow and variable training.** The backpropagation example runs 180,000 iterations, and the README warns that results vary with initialisation and runtime.
- **Unfinished parts.** The README calls the collection a work in progress. Notebook 8 still has unfilled `# Write your code here` task cells, and notebooks 7 and 8 have no stored outputs, so this page does not claim all eight run end to end.

## Results

- Notebooks 1 to 6 keep stored outputs. Backpropagation on XOR ends at an average error of 0.00861 (`backward-propagation.ipynb`).
- Dense MNIST classifier reaches 98.11% accuracy after 10 epochs; the CNN variants reach 98.07% to 98.86% (`classification-with-keras.ipynb`, `convolutional-neural-networks-with-keras.ipynb`).
- These runs pass the test set as `validation_data`, so they are test-set numbers also watched during training, not held-out results. The README calls them teaching examples, not benchmarks.
- The repo adds a Colab-first README with per-notebook Open-in-Colab links, `CONTRIBUTING.md`, a code of conduct, and semantic-release configuration.
