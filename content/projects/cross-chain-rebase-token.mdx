## Overview

A cross-chain rebase token protocol. Users deposit into a vault and receive a yield-bearing balance, and the interest rate they earned is preserved when the token is bridged to another network using Chainlink CCIP.

## Stack

- **Contracts:** Solidity with OpenZeppelin
- **Tooling and tests:** Foundry
- **Cross-chain messaging:** Chainlink CCIP
- **CI:** GitHub Actions

## Key ideas

- Balances grow over time, so holders see yield accrue without claiming it.
- Bridging carries the holder's interest rate with them, so moving chains neither resets nor inflates what they have earned.
